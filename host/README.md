# 音色设计台与电脑演奏

当前唯一入口是 `run_tone_studio.bat`；旧综合控制台已删除，历史在Git提交 `f513622`。`studio.py` 负责交互，`studio_ui.py` 绘制界面，`studio_transport.py` 串口/模拟设备，`studio_model.py` 保存配置并生成单周期波表。

## 启动

双击 `host/run_tone_studio.bat`，或从仓库根执行：

```powershell
& '.venv-studio/Scripts/python.exe' host/studio.py
```

首次使用其他电脑按 `setup_studio.ps1` 建立虚拟环境，依赖见 `studio_requirements.txt`。模拟设备不发声，只用于交互测试。

连接实际COM口，115200/8N1，当前固件报告 `TONE=PIANO_ROCK`、`MAX_VOICES=16`。收到握手和实际PRESET状态后，演奏台可选择钢琴或摇滚电吉他、弹琴、调总音量／±2半音弯音、查看状态与全部松键。音量／弯音须收到CONTROL能力及完整状态后启用；“弯音归中”恢复原音高，音量0静音但不释放声部。选择音色需等设备回执，新触发的音使用新预设，已有声音自然延续。当前固件无CONFIG能力，设计页“应用”禁用；修改设计页草稿滑条或载入JSON不会改变板上音色。不要同时用串口终端占用该COM口。旧固定钢琴固件仍兼容。

界面可编辑16谐波与包络草稿、保存/读取JSON、导出1024点16位单周期波表；这是开发工具，不是电脑替代FPGA发声。`tone_examples/piano.json` 仅为音色工作台的可编辑示例，当前主固件模态参数见 `model/gen_piano_v3_rom.py`，不是录音PCM。演奏台的总音量／弯音已接入当前FPGA；设计页谐波／包络草稿、混响及颤音仍未接入。

## 验证与协议

```powershell
& '.venv-studio/Scripts/python.exe' -m unittest discover -s host -p 'test_*.py' -v
```

协议定义见 [STUDIO_PROTOCOL.md](STUDIO_PROTOCOL.md)，其中CONFIG章节仅为PC/模拟设备能力。实体按键与PC共享16声部（含尾音）；PANIC只清理PC来源，固件包含3秒失联回收。用户已反馈旧版实际握手和基础演奏可用；classic16已有用户初步可用反馈，完整音质／稳定性仍需逐项验证，不能用模拟设备状态作为比赛证据。


连续拖动演奏滑条时，上位机按40ms合并最新完整参数对，只保留一个在途请求；设备报告目标值后再发送后续变化。界面分别显示设备目标和待确认／待发送，等待时仍可弹奏、松键。超时或拒绝后查询状态，不自动重放旧请求；断连清理待发送值。旧固件缺少CONTROL时禁用这两个控制，原有弹奏可继续。GUI调节响应不能当作实体旋钮通路的延迟验收。


## 2026-10-14演奏试听入口

关闭旧GUI后重新运行启动脚本；“演奏”页的“总音量”控制实际声音，工作台“草稿音量”只改变草稿。新固件`music-live16`的开机／KEY0复位音量为8/127、弯音居中；旧固件仍按它自己的复位值工作，更新GUI不会改写固件默认值。

先确认实际音量，再选择钢琴或摇滚：

- **低中高音试听**：C3、C4、C5、C6依次按住1.2秒，松键后间隔0.2秒。
- **C3–C6 音阶扫描**：MIDI48～84共37个半音，每音按住0.25秒、间隔0.2秒。
- **16音测试**：MIDI48、50……78共16音，发送按键命令后保持2秒再松开。开始前松开板键；这是压力输入，密集和声不好听不能据此判音色失败。下面显示设备定期报告的VOICE_COUNT，包含尾音。

上述操作使用当前预设、音量与弯音，只发送控制事件，不播放电脑音频。开始时清理旧PC音并留0.2秒尾音间隔；不会清理仍按住的板键。串口命令逐条发送，16音并非在同一个FPGA时钟沿触发。普通“四音和弦”按钮保持原有手动松键行为。

“全部松键”、手动弹键、切换预设、切换页面／窗口、断连或会话失效会取消自动队列；旧定时事件不会再次发音或松掉后来手动弹的音。自动序列结束不代表听感通过。需要听更长衰减时可手动持音。

本次58项离线测试通过，其中9项覆盖试听配对、全音域序列、容量门槛、取消、手动重按、连接失效、预设切换和发送故障。图示`build/host/studio_live16.png`是模拟传输界面，不是真板截图。完整逐项标准见[试听验收](../docs/listening-acceptance.md)。


## 经典摇滚候选（2026-10-14）

当前新位流身份为`music-classic16`；`PRESET 0`仍选摇滚，默认仍为钢琴、音量8、弯音居中。较旧`music-live16`版，本轮减轻摇滚失真并补偿单音响度，不新增用户必须配置的参数。旧固件依然兼容。

重启GUI后，“演奏”页新增“五度和弦”：C4/G4/C5（60/67/72）三个音，点一次保持，点“全部松键”释放；它也会取消正在运行的自动试听。与普通四音和弦、低中高音、16音按钮配合进行对比，窗口失焦仍会释放电脑音符。60项PC测试通过，包含这项输入与取消／容量保护；截图`build/host/studio_classic16.png`是模拟传输。
