# FPGA 多音色电子乐器：团队方案与开发进度

### 器件清单与采购边界

| 器件 | 数量 | 必须核对 |
|---|---:|---|
| KY-004类瞬时按键模块 | 13个 | 已焊排针，逐个独立读取，核对引脚顺序和输出极性 |
| B10K线性电位器模块 | 2个 | 带旋钮、已焊接头，可在3.3V下使用 |
| ADS1115模块 | 1块 | 已焊排针，整板3.3V供电，I2C上拉不得接5V |
| 面包板／免焊配线板 | 1套 | 电源、地及必要上拉分配 |
| 杜邦线及匹配线缆 | 1套 | 覆盖全部模块与板卡连接 |
| 电阻、电容 | 1小包 | 必要上拉、去耦 |
| 固定底板、绝缘固定件、标签 | 1套 | 黑白键布局、模块固定和线材拉力保护 |

ADS1115只采集两个慢变化旋钮，不承担音频采样；双通道更新延迟需要验证。器件依据见 [TI官方数据手册](https://www.ti.com/lit/ds/symlink/ads1115.pdf)。不额外购买处理器、按键扩展芯片或外放音箱。

C整理候选模块和价格，B核对供电、电平、接口及接头，三人确认后采购。若合格器件超预算，暂停并重新评估，不擅自减键或要求焊接。

预计新增13路按键输入、2路I2C信号。B必须先依据31004原理图与模块资料完成接线表，再连接实物；PMOD与复用排针不能当作两组独立资源。当前 demo 的 CST **不包含这批新增外设约束**。

## 三人分工与交付物

责任边界：**C决定弹哪个音、何时触发／松开；A生成各声部并混音；B（你）连接整套系统并稳定输出。** 三人都按新手起点推进，每人负责自己模块的说明、仿真和修复，不把全部开发交给B。

### A：合成与音色

- 输入：各声部音符、触发、保持／释放、音色，以及整体音量和变调参数。
- 输出：16位有符号混音样本、样本有效、各声部释放完成反馈。
- 复用 `phase_acc`、`wave_lut`、`voice_dds` 和音符步长查表；四声部保持独立相位、音高和包络。
- 实现完整 `adsr_envelope`、柔和／明亮两种波表、实时变调、音量平滑、宽位混音与饱和。模块可合理合并，不复制四份声部源码。
- 初始包络：起音2ms、衰减500ms、保持约峰值10%、释放120ms；松键从当前包络值开始释放。
- 交付：RTL、波表生成依据／脚本、Python参考模型、逐样本对照与正常／边界／复位测试结果、输出延迟说明。
- 第一项实验：单声部包络，检查正常松键及起音／衰减中提前松键，然后扩展四声部。

### B：音频输出与系统集成

- 输入：A的音频样本、C的控制就绪／故障状态；输出：音频串行信号、静音控制和完整工程。
- 维护 `sample_tick`、`i2s_tx`、`synth_top`；负责新电子琴顶层连接、统一时钟／复位、启动和异常静音。
- 明确采样请求、样本有效、缓存接收和实际发送时刻；检查正常播放缺样本。
- 负责高云工程、CST／SDC约束、接线表、综合／布局布线／约束覆盖与时序告警检查。
- 协调联合仿真、上板和后续整机测量，记录源码／下载文件版本及工具报告；接口两端共同定位问题。
- 交付：可打开的工程、顶层RTL、约束、接线表、联合测试、构建／下载／测试说明与记录。
- 第一项实验：用可预测样本验证“请求→有效→缓存→输出”，覆盖首帧静音和中途复位。

### C：输入与声部分配

- 输入：13个按键、两个旋钮的ADC数据、A的释放完成反馈；输出：四声部控制、整体音量、变调和故障状态。
- 扩展 `input_sync_debounce`、`touch_or_key_if`、`event_encoder`、`voice_allocator`、`interaction_top`；音符映射改为连续的60～72，不能沿用当前两键C4／E4映射。
- 新增ADS1115初始化、I2C读写、双通道轮询、旋钮数值映射及错误／数据失效检测；现有 `pressure_if` 不等于ADC驱动，本版不接压力。
- 完善四声部分配、松键、释放、重触发、第五键抢占；接入音色选择，不能继续把音色固定为0。
- 交付：输入与分配RTL、ADC驱动、模块接线资料、按键／事件／ADC模拟器测试与结果。
- 第一项实验：模拟四键同时按下，再加入第五键，验证分配和松键不关错声部。

### 共同接口规则（下一版实现前确认并写入测试）

| 接口 | 两端共同负责的约定 |
|---|---|
| C → A | 音符、独立触发、保持／释放、音色、音量、变调的位宽、符号、单位和有效时刻；持续高电平不能单独表示重触发 |
| A → C | 每声部真实释放完成；尾音结束前不能当作空闲 |
| A → B | 请求到有效的周期数、16位有符号格式、缓存接收时刻和缺样本处理 |
| C → B | 控制就绪、通信故障、数据失效与恢复条件 |
| B → A/C | 统一时钟、复位及运行条件 |

- 沿用50MHz系统时钟、48kHz目标采样率、16位输出；I2C时钟只作外部信号，不另建内部逻辑时钟域。
- A在采样边界采纳参数并平滑音量／变调；变调不得修改松键匹配用的原始音符编号。
- 分配顺序为空闲、释放中、最老活动声部；被抢占琴键松开不能关闭新音符。
- 下一版 KEY0复位、KEY1切换音色、KEY2预留；切换只影响新触发声部，旧尾音保持原音色。**当前 demo 仍是 KEY1=C4、KEY2=E4。**
- ADC初始化失败、持续通信失败或数据长期失效时静音；恢复后先松开琴键，再重新演奏。
- A检查C、B检查A、C检查B；三人都逐步掌握仿真、构建、下载和本模块解释。
