# 官方赛题指标核查：2026-10-25

核查对象：`projects/hdmi/piano_hdmi.gprj` 的正式 `piano_hdmi_top`，包括当前未提交工作区。结论针对当前源码和绑定到该源码的离线证据；实物验收单独列示。

依据：[高云半导体2026 FPGA赛道选题指南](sources/全国大学生嵌入式芯片与系统设计竞赛'2026FPGA赛道选题指南-高云半导体.pdf)，选题二，印刷第13—14页，即PDF文件第15—16页。原文提取、PDF哈希和逐项核查结果见 `build/contest_metrics_audit_20261025/source_requirements.txt`、同目录 `summary.json`；复核脚本为同目录 `audit.py`。

## 数值指标

“离线满足”表示正式配置、源码和对应功能测试支持该数值，不代替比赛现场的模拟输出验收。

| 条款 | 官方指标 | 当前值/证据 | 结论 |
| --- | --- | --- | --- |
| 基础1 | 至少2个独立可控维度 | 音量、连续弯音、明亮度，共3维；前两项来自AIN0/AIN1，第三项来自AIN2，分别作用于增益、音高比和滤波响应 | 离线满足；实体操作仍待验收 |
| 基础2 | 控制信号到音频输出总延迟≤10ms | 尚无实体键或USB触摸到模拟输出的整机测量与最坏情况上界 | 未验证，不能判达标 |
| 基础3 | 基础复音数≥4 | 正式32声部；每声部保留独立音符/音色/包络和相位状态 | 离线满足 |
| 拓展1 | 复音数≥32，或单音加法分量≥32，或多条并行物理建模运算单元 | 选择32复音路线，两组16声部并行；无需同时满足其余替代路线 | 离线满足；现场频谱证据未完成 |
| 拓展2 | ≥3维演奏表情 | 音量、连续弯音、明亮度，共3维；音区/音色切换和固定效果器未计入维度 | 数量离线满足 |
| 拓展2 | ≥2种乐器音色自由切换 | 钢琴、电吉他，共2种；新起音采纳当前音色，旧声部保留其原音色 | 离线满足 |
| 拓展3 | 演奏延迟≤5ms | 无两条整机通路的模拟输出测量 | 未验证，不能判达标 |
| 拓展3 | 确定性无抖动延迟 | 只有固定内部计算拍数和音频截止时间证据，没有完整输入到模拟输出的延迟变化证据 | 未验证，不能判达标 |

官方数值使用“≤5ms”，不是截图中的“低于5ms”。正式内部原始PCM在R925完成、含增强明亮度和三效果的缓存为R958，即958/50MHz=19.16µs；该时间不能替代输入扫描、触摸报告、消抖、事件等待、DAC串行和模拟输出的总延迟。

## 核心吞吐量与现场证据

官方评分以“同时活跃可闻独立振荡器总数×实际音频输出采样率”为依据，没有另列最低采样率。当前设计采样率为48kHz，保守按完整32声部计算的名义声部吞吐为 **1,536,000声部采样/秒**。该数不是已验收的实际振荡器评分，也不把左右声道复制或每声部的ROM槽位数直接当作附加得分。

当前源码绑定的 `tb_brightness_hdmi` 记录通过：13实体键加19个UART音符填满32声部、逐声部非零贡献、第33音抢占、两音色、真实AIN2路径、6903个音频样本、13803个DAC串行字，以及R958截止时间；其中2291个样本处于32声部配置。不能把该数字仿真等同于实物48kHz或对应数量谱峰的测量。

现场要求的不同频率输出、对应独立谱峰及实际采样率证据仍未完成。可通过现有多音符控制路径设置不同音高，但尚未取得现场频谱记录。

## 非数值条款与边界

| 原文条款 | 当前核查 |
| --- | --- |
| FPGA HDL逐音、逐样本实时合成，禁止预录PCM/整段录音触发 | 合成、包络、混音、滤波、三效果及DAC链路均在HDL内；ROM保存正弦表和模态系数，曲谱存储只保存演奏/导奏事件，符合实时生成的结构要求 |
| 通过I2S输出至DAC | **存在原文接口差异**：`rtl/audio/i2s_tx.v`明确实现PT8211的16位LSBJ/右对齐格式，不是标准延后一位的I2S。不能因文件名含I2S或DAC能发声就勾选此条；需要正式口径确认或提供符合标准I2S的实际输出链路 |
| 支持ADSR包络调控 | 有ADSR状态机和32份独立包络状态；正式预设D=1采样、S=65536/65536，因此D段幅度不下降，模态核心另有自然衰减。PDF没有要求运行时可调四个参数，不能仅凭预设固定认定不合规；典型A/D/S/R四段的演示证据仍需明确 |
| 力度动态、滑音、颤音等演奏效果 | 远程音符支持velocity，实体键固定velocity=100；连续弯音、延音已接入，独立颤音表情没有接入。三维数量与列举效果的实现完整性分别说明 |
| FPGA内部混响、延迟、合唱等效果 | 三者均已实现且正式默认开启。原文没有单独规定最少效果种类数，也没有要求所有参数实时可调 |
| FPGA实时可视化反馈 | 有波形、持键高亮和状态显示；原文没有单列最少可视化种类数，不要求把全部列举示例都计为独立数值门槛 |
| 脱机演奏LED曲目指引 | 有42音固定节拍屏幕导奏及下载曲谱导奏，没有字面上的LED曲目指引；屏幕替代是否认可尚未确认 |
| 蓝牙/App与曲谱、键位、录音回传拓展 | 板端已接曲谱传入、最多512段、13键映射、控制与实际状态回读；实物手机联合验收未完成，录音回传未实现。此段以“可搭载”引入，不能把所有列举功能擅自改为数值门槛 |

截图中的增益管理属于工程质量核查：目前有扩位累加、缩放和饱和保护，饱和本身不能证明无削波；PDF没有给出独立的零削波数值门槛。该质量问题应保留测试，不能用它替代复音数、控制维度或总延迟指标的判定。
