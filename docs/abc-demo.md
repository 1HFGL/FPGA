# A+B+C 板级 demo：使用与验证

## 范围与来源

这是阶段性接线 demo，不是赛题验收。C 来源为团队仓库 `1HFGL/FPGA` 的 `Part_C` 提交 `b758cac`，已包含在 `master` 的 `1048ddf` 中；未把 `Part_C_` 的电脑音乐程序放进 FPGA 发声链路。原 C 源码/测试保留，原说明另存 `docs/c-interaction.md`。

复用 A 的 `voice_dds`（直接数字合成，DDS）四次，复用 B 的采样请求与 PT8211-S 串行输出。新增 `note_phase_lut`、`demo_voice_bank`、`instrument_demo_top` 负责音符转换、简单包络、混音与连接；新集成代码用中文注释，未覆盖用户的已有注释修改。

## 两种演示方式

| 模式 | 顶层 / 输出文件 | 操作与预期 |
|---|---|---|
| 普通两键 | `instrument_demo_top` / `instrument_demo.fs` | S2 按住发 C4，S1 按住发 E4，可同时按；松开渐出 |
| 自动四声部 | `instrument_demo_auto_top` / `instrument_demo_auto.fs` | 每次 S4 复位后，四路独立正弦播放一次约 1 秒，再释放静音；普通键不起作用 |

自动音符是 C 测试发生器原有的 MIDI 36/37/38/39，不是悦耳和弦预设；每路有独立相位/音高/包络。普通模式只有两个演奏键，不能据此宣称两维传感器或者四键演奏已经实现。

## 板卡和约束

用户已确认 NEO Dock 31004。约束依据用户提供的 Rev1.4（2025-03-31）原理图与厂家全板 CST，只选用以下 8 个端口。

| 信号 | FPGA 引脚 | 电平 / 用途 |
|---|---|---|
| sys_clk | V22 | 3.3V，SOM OSC 名义 50MHz |
| sys_rst_n | AA13 | 1.5V，上拉，S4 低有效复位 |
| Key_in[0] | AB13 | 1.5V，上拉，S2，C4 |
| Key_in[1] | Y12 | 1.5V，上拉，S1，E4 |
| HP_BCK | Y17 | 3.3V，DAC 位时钟 |
| HP_WS | AB17 | 3.3V，DAC 声道选择 |
| HP_DIN | AA16 | 3.3V，DAC 数据 |
| PA_EN | AB16 | 3.3V，1=功放关闭，0=开启 |

原先把 25MHz 当作 V22 的说明已纠正。25MHz 是 MS5351 的参考晶体；AB12 是另外的可编程时钟输入，本 demo 不使用它。旧通用 A+B 参数仍可用于仿真，但不是板级时钟。

SDC 只有一个 20ns 主时钟。BCK 是输出信号，不在 FPGA 内当时钟；全部逻辑共享 sys_clk。异步按键仅到第一同步级的输入不做同步时序分析，后级同步路径仍受主时钟约束。外部复位异步断言、B 两拍同步释放；A/C 共用 `audio_ready`，复位期间关闭功放。

输出的 0..20ns 约束是寄存器到引脚的本地布线预算，**不是完整 PT8211-S 外部时序验收**。输出采用分数时钟使能，帧间隔为 1041/1042 个主时钟，平均 48kHz；BCK 半周期为 16/17 个主时钟。实际抖动、DAC 建立/保持余量和板上时钟还需测量，不能把工具 Fmax 当作板卡实测性能。

## 样本和数值契约

- C 分配四个槽，输出各自 gate（按住状态）、音符、力度；分配时 ready/valid 的原握手保留。
- 普通键力度固定 100/127，压力/表情/音色输出没有接入 demo，不支持实时外部调音。
- 音符到步长：`round(440*2^((note-69)/12)*2^32/48000)`；128 项均由 Python 数学参考核对。
- 起音每采样 +8，8 位包络饱和到 255（32 个采样约 0.67ms）；释放每采样 -4，饱和到 0（最多 64 个采样约 1.33ms）。只是 attack/release 渐变，不是完整 ADSR。
- 每声部 16 位有符号正弦，包络×力度为 15 位无符号增益，补零转正有符号数，乘积 32 位；`>>>15` 后四路显式扩到 18 位累加，再 `>>>5`。算术移位对负数向负无穷取整。结果界限约 ±4049（全幅的 12.4%），不依赖溢出截断。
- 请求沿 R0：查旧相位、更新包络、快照力度；R1：乘法结果；R2：混音有效；R3：B 缓存；下一个音频帧边界发送。请求间至少留 4 个主时钟，实物参数约 1041 个。
- 首个帧没有先前样本，发送零并标记欠载；之后每帧应有新样本。左右发送相同样本。
- 只有 gate 已低且包络回到零才给 C `release_done`，避免提前丢弃尾音。相位随采样连续推进，换音/重触发不强制清相位；全局复位会清零独立相位。
- PT8211-S 使用 16 位 LSBJ（右对齐）：WS=0 右声道，WS=1 左声道，下降沿准备数据，上升沿采样。名称 `i2s_tx` 是沿用模块名，不能将其宣称为 Philips I2S 格式；比赛最终接口口径需确认。

## 复现

从仓库根目录执行，ModelSim 路径换成自己的安装目录：

```powershell
.\sim\run_tests.ps1 -Suite All -ModelSimBin 'C:\Library\modelsim\win64'
python model/check_dds.py
python model/check_abc_demo.py
```

若 `python` 是 Windows Store 别名，请使用真实 Python 3 可执行文件。两份 Python 模型只做开发验证，不参与最终发声。

高云 EDA 打开 `fpga_project/fpga_project.gprj`；默认普通键版。构建两版的准确命令见 `fpga_project/README.md`。不能只拷贝 `.gprj`，必须保留 RTL、ROM、boards 和工程配置的相对目录。

## 实际验证记录（2026-09-30）

- ModelSim SE-64 10.6e：原 A 三项、B 两项、AB 一项、C 六项、新增两项，共 14 项自检通过；最后一次整合回归 0 编译警告，新增集成测试 0 仿真警告。
- Python 3：1024 项正弦波表、4810 项 A 样本；128 音符步长、745 项四路混音、2 次混音复位逐项吻合。
- 边界覆盖：力度 0/127、正负输出、空闲静音、包络饱和和释放、运行中换音、按键短抖动、两键和弦、中途复位及复位后按住重触发。
- 自动事件模式的峰值声部分配数为 4；四路混音已数字验证，**四路可闻声部及频谱仍待实物确认**。
- 负向 AB 对照故意翻转串行观察位，产生 `expected=0000 actual=8000`，脚本以非零状态拒绝，没有把变异 RTL 留在交付物中。
- Gowin 1.9.12.04，GW5AT-60B / LV60PG484AC1/I0 / B：普通/自动版综合、布局布线及 bitstream 生成均完成，8/8 端口 `Constraint=Y`，主时钟与输出预算约束在报告中为 Actived，setup/hold 违例均为 0。
- 普通版：842 LUT、232 ALU、790 寄存器、4 pROM、6 DSP；自动版：1568 LUT、227 ALU、628 寄存器、4 pROM、6 DSP。只是本次工具报告，不外推板卡能力。
- 普通版报告内部 Fmax 110.689MHz，自动版 94.232MHz，均按 50MHz 构建；不用于宣称实测性能。
- `NL0002`：未使用压力/测试/按键模块按模式被优化，符合本 demo 范围；`PR1014`：V22 非专用时钟输入使用通用路由连接全局时钟，保留告警。报告显示核心使用一个 PRIMARY；完整硬件时钟可靠性与外部 DAC 时序尚未签核。

证据存于 `results/abc-demo-20260930/`：源文件/约束/下载文件 SHA256、原始布局布线与时序报告、14 项日志和混音 trace。大体积 `.fs` 可在本机生成，不提交工具工作库；旧 A+B/C 工程文件仅作历史参考。

## 上板最小实验

1. 检查自己仍是 31004、供电和 DEBUG USB 数据连接正确。把音频负载/耳机先放下，不戴在耳朵上直接试听。
2. 重新生成普通版；查看报告中以上 8 个引脚与 IO 电平均正确且 Constraint=Y，确认时序与告警没有新的变化。
3. Programmer 选择匹配 GW5AT-60B 的 **SRAM Program** 与本轮 `instrument_demo.fs`。不要选旧 `fpga_project.fs`，不刷 Flash、不改调试器固件。
4. 下载成功后按 S4 复位，松手应静音；低音量连接已确认的板载 3.5mm 耳机输出，分别按 S2/S1，再同时按，松手应很快静音。无声音时先核对时钟/功放/串行波形，不先加大增益。
5. 普通版确认后再试自动版 `instrument_demo_auto.fs`；按 S4 后播放一次约 1 秒，之后静音。断电会丢失 SRAM 配置，这是正常的临时测试方式。
6. 记录成功下载日志、实际操作/声音和板卡版本。助手未执行下载，现有截图也不作为本轮成功发声的证据。

原理图的 J27/J28 为桥接扬声器端，**不能把任一端接到接地示波器的地夹**。数字测量先在正确公共地参考下测 BCK/WS/DIN；模拟输出测量须先核实负载与安全接法。

后续最小开发项是实物闭环、完整 ADSR、第二音色、压力/第二维输入、表达参数映射与实际整机延迟测量。未测整机时不能声称 ≤10ms；未核对比赛标准 I2S 口径时不能宣称 R6 验收完成。
