## 已实现的行为

- 四个声部可以分别起音、衰减、保持、释放，不共享相位或包络状态。
- 松键从当前电平释放；起音/衰减中提前松键也保留尾音。
- 持续按住时的独立重触发、释放中的重按和同槽位换音由各路触发控制；相位保持连续。
- 每路请求时快照增益，支持逐拍连续请求，不混用相邻样本参数。
- 四路显式扩位相加、统一缩放，再饱和到有符号 16 位，避免溢出反转。
- 释放反馈包含内部流水线尾音，最终零样本到达混音输出后才回收。

声部分配和第五键抢占策略仍由 C 决定。本次仅模拟 C 已选择一个槽位并换音/重触发的输入行为，不宣称已经升级 C 的分配器。

## 文件与接口

| 文件 | 作用 |
|---|---|
| `rtl/voice_bank_adsr.v` | 四路声部、参数快照、释放完成反馈 |
| `rtl/sample_mixer4.v` | 四路混音、缩放、饱和 |
| `sim/tb_voice_bank_adsr.sv` | 数学参考、逐时钟流水线/反馈检查与轨迹导出 |
| `sim/tb_sample_mixer4.sv` | 有符号极值、相消、舍入、饱和与复位测试 |
| `model/check_poly_adsr.py` | Python 闭式包络、独立正弦和整数流水线参考 |
| `sim/run_poly_adsr.tcl` | ModelSim 波形入口 |

`voice_bank_adsr` 的全部控制都应位于 `clk` 域。`sample_request` 是时钟使能，不能接到时钟端口。`rst_n` 是低有效同步复位，须经过至少一个时钟边沿；未来接入统一复位逻辑。

| 端口 | 含义 |
|---|---|
| `voice_gate[3:0]` | 各声部保持状态；松键清零，尾音期间仍需请求采样 |
| `voice_retrigger[3:0]` | 各路一个 `clk` 的触发脉冲；不得长时间保持为 1 |
| `voice_note_flat[27:0]` | 四个 7 位 MIDI 音符，声部 0 在 `[6:0]` |
| `voice_velocity_flat[27:0]` | 兼容旧 demo 的数字增益字段；0 静音，127 单位增益，1~126 按值/128 缩放 |
| `sample_data/sample_valid` | 16 位有符号混音样本及有效指示；无效周期保持数据 |
| `sample_clipped` | 有效输出是否饱和；无效周期为 0 |
| `release_done[3:0]` | 每声部空闲/尾音结束反馈；复位时为 `1111` |
| `voice_active[3:0]/sounding` | 保持、包络或内部尾音仍存在；`sounding` 为四路合并 |
| `env_level_flat[67:0]` | 四个 17 位无符号 Q1.16 包络电平，声部 0 在最低 17 位；65536 为单位增益 |

增益字段沿用已有数字接口，不要求增加力度传感器。本版普通按键可固定为 127；全局音量/实时变调平滑与两种波表是后续任务。

音符/增益在请求边沿采纳。两次请求间的触发会暂存，多个脉冲合并一次，不是事件队列。触发要配合保持状态及新音符；松键优先于触发，`gate=0` 时会放弃待处理触发。换音本身不会自动重触发，必须给明确脉冲，才能覆盖同音符重新触发和持续保持时抢占的情况。

## 默认参数与输出时刻

音符步长查表按平均 **48 kHz** 计算。默认包络沿用单声部：A=96、D=24000、S=6554、R=5760，对应起音 2 ms、衰减 500 ms、保持约 10%、释放 120 ms。0 点时长按 1 点立即完成，保持电平超过 65536 时钳位。

`MIX_SHIFT=5` 为默认试听配置，四路总和除以 32，理论输出范围 `[-4096,4095]`。`MIX_SHIFT=0` 不缩小总和，超出 `[-32768,32767]` 时饱和。该参数有效范围为 0~17。

| 上升沿 | 更新内容 |
|---|---|
| R0 | 接受请求，DDS 读取旧相位、推进包络，快照各路增益 |
| R1 | 输出各路 ADSR 样本 |
| R2 | 输出各路增益缩放样本 |
| R3 | 混音、`sample_valid` 与饱和标志一起更新 |
| R4 | 同步下游可以读取 R3 的样本 |

因此请求后经过 **3 个时钟间隔**输出有效；50 MHz 下对应内部 60 ns，下游在 R4 读取。支持连续请求，其 valid 可以连续为 1。本次不是整机端到端延迟测量。

旧 `demo_voice_bank` 在 R2 输出，本模块增加一拍。未来接入前，B 必须核对缓存与发送时刻；C 必须确认独立触发的产生方式及释放反馈。`release_done` 表示该声部的最后零样本已推进到内部混音输出，不表示 DAC 已经播放完对应帧。
