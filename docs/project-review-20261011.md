## 整体通路与边界

```text
电脑UART → 接收FIFO/命令解析 ─┐
板上KEY1/2 → 同步消抖/事件 ─┴→ 来源仲裁 → C：声部分配器
                                            ↓ 四路音高/力度/gate/重触发
                                 A：DDS波表 → ADSR包络 → 力度 → 饱和混音
                                            ↓ 样本 + sample_valid
                                 B：样本缓存 → DAC串行发送 → PT8211 → 耳机
                                 ↑ release_done反馈到分配器，不能提前回收尾音
```

所有现有主通路状态使用50MHz同一时钟；48kHz是采样使能，不是另造低速逻辑时钟。B统一处理复位：异步断言、同步释放。DDS是相位累加后查单周期波表；ADSR是起音、衰减、保持、释放的幅度控制。

|---|---|
| `fpga_project/uart_piano/uart_piano.gprj` | 主工程；四声部固定钢琴感预设，电脑演奏及两个板键 |
| `fpga_project/uart_basic/uart_basic.gprj` | 同一控制通路的固定正弦基线 |

## 按收益排序的简单优化建议

1. **先补约束证据，不提频。** 当前最差总体路径为力度乘法结果到PA_EN（+6.435ns）；最差内部路径是UART RX FIFO读指针→命令解析寄存器（+6.468ns，13级逻辑），不是音色乘法。保持50MHz，优先核对实际时钟接入和DAC相对BCK时序。不要用虚假路径/多周期约束掩盖组合延迟。
2. **扩16时先保留简单并行方案并实测。** 参数化bank、总线、分配器和能力上报；混音改平衡树，16路16位相加至少20位，再统一舍入/饱和。接口声明新增延迟，保留每声部独立相位和包络。只有资源报告显示压力时，再共享ROM或乘法器；不先写完整微调度器。
3. **若控制通路成为瓶颈，再处理FIFO队头。** `uart_fifo.v`是异步读，64字节队头选择组合地进入解析器。可实验“同步读/预取寄存器＋valid/ready”，必须重新验证空满、同拍进出、flush和取消事件，不能直接加一拍导致重复/丢字节。当前仍有裕量，本轮不改。
4. **小宽度优化排在后面。** `sample_tick.v`的帧半边沿计数当前16位，默认只需6位；相位余数在50MHz下只需26位，求和要额外一位。可以参数化宽度，但综合器可能已裁剪部分位，节省量必须以改前改后报告确认。ADSR已按最大段长收窄计数器，不重复优化。
5. **音质不是靠增加同一张波表的声部数。** 当前钢琴固定谐波比例，16路只是能同时弹更多音。优先用队友已实现的“基波/丰富谐波随时间混合”机制实验钢琴高频先衰减，再与用户认可的干声参考对比。不能用长段PCM录音替换实时合成核心。

50MHz/48kHz每采样约1041.67拍，未来确有分时计算空间，但状态读写、音符事件、ROM/乘法器流水及混音都必须计入最坏周期预算。这只是预算依据，不是16/32声部已经验证。
