# 当前音频通路与模块职责

本轮主工程已接通16声部与双旋钮；触摸、显示顶层、实物音色及整机延迟仍待验证。

## 数据流

```text
板键 → 同步/2ms消抖 → 事件编码 ─┐
UART → 收字节/组行/命令解析 ───┼→事件仲裁→voice_allocator
                              └→16路音高/保持/起音代次/力度
                                 ↓
                  voice_bank_adsr → 全局音量 → sample_data/valid
                                 ↓
                    synth_top → i2s_tx → 板载DAC/功放
```

正式入口 `piano_performance_top` 连接ADS1115和16声部公共系统 `instrument_uart_top`。两个旧名称的板级薄封装继续服务原有接口测试，共用同一参数化核心。当前一个50MHz系统时钟，目标48kHz采样；采样请求是时钟使能，不是另造逻辑时钟。复位来自B的统一就绪信号，异步断言后同步释放；功放复位立即关闭。

## 为什么有几个名字相似的文件

| 模块 | 作用 |
| --- | --- |
| `adsr_env` | 一个音的起音、衰减、保持、释放电平 |
| `phase_acc` / `wave_lut` | 独立相位累加与同步单周期查表，即DDS直接数字合成 |
| `voice_adsr` | 单音DDS和包络的基础验证组合，仍有当前单元测试 |
| `voice_timbre_adsr` | 主钢琴实际使用的单声部，支持触发时锁存波表选择 |
| `voice_bank_adsr` | 参数化组织独立声部，正式16路，默认4路；力度缩放、代次确认、尾音和混音 |
| `voice_allocator` | 处理输入来源、音符归属、重触发、释放和抢占，不直接合成声音 |
| `voice_bank_instruments` | A的新吉他/弦乐独立合成，不是旧钢琴备份 |

旧`adsr_voice_bank`、旧渐变`demo_voice_bank`及其专用测试/旧顶层已经删除。单音链路夹具放在`verification/tb/integration`，仅用于验证，不作为第二套板级主工程。

## 样本有效时刻

- R0：接受请求，寄存弯音乘积和整组gate/力度/音色/起音代次，避免不同事件拼成一个样本。
- R1：DDS/包络采样并确认代次；R2：包络乘法；R3：力度；R4：16路混音；R5：全局音量与`sample_valid`；R6：发送器缓存。默认4路/关闭控制配置保持R0 DDS、R3混音、R4缓存。
- 主钢琴在真实帧起点前32/33个系统拍发请求，通用默认lead=0兼容独立测试。R0/R1是系统时钟沿，不是音频帧。
- `i2s_tx`按完整左右声道帧发送同一缓存。边界同拍提交属于下一缓存，不能旁路半帧；缺新样本时的行为由缓存测试检查。
- C只在包络与混音尾音真正结束后回收声部。`sounding`变低不代表DAC已播完，功放还要按真实帧计数等待排空。

增益使用17位无符号Q1.16，16路16位有符号样本先扩为20位，以4级平衡加法树求和。主钢琴`MIX_SHIFT=5`保留低音量余量；`sample_mixer4`显式饱和，不能靠隐式截断。力度127为单位增益、1..126按值/128，默认100。

## 双旋钮与事件合同

`ads1115_if`轮询AIN0/1，PGA±4.096V、128SPS、每通道固定等待10ms；`ads1115_knob_if`按0..26400码对应0..3.3V标定，再由C原滤波/限速逻辑生成两路7位值。参数对有效且ready、无fault时成对接收。16对采样预热、IIR滤波和每对最多8级限速造成明显响应时间，可能数百毫秒；本轮没有优化或实测这一段，不能由按键2ms数字结果推定旋钮≤10ms。

`piano_controls`将音量映射为round(65536×value/127)，0静音、127单位增益。弯音0..62映射−200..接近0音分，63/64中心为0，65..127映射正值至+200；频率比round(65536×2^(cents/1200))，Q2.16端点58386/73562。32×18位乘积保留50位，加32768后取[47:16]，音符范围0..127与±2半音下不溢出32位。音量每采样最多变化1024/65536，频率比最多256/65536，目标固定后最多64次更新收敛；参数接受到对应输出另包含采样等待和6拍流水线。

音高变化保留相位与包络，作用于全部保持音、尾音及新音。复位恢复原工程音量和原音高；ADC未ready不覆盖默认值，运行故障保持最后有效参数。混音先20位累加/缩放并饱和，最后乘无符号Q1.16总增益，带符号算术右移向负无穷取整。全局音量与每音固定力度分开。

事件在上升沿valid&&ready时接收；每键4项暂存，64项FIFO，轮转搬运。溢出后锁存故障并停止本地投递；实体来源0..12，清理掩码0xF0/值0仅清0..15；PC来源0x80|note，清理掩码0x80/值0x80。背压保持队头。16位起音代次在声部分配时递增，A在R1实际消费后确认，回收还需gate关闭、尾音完成且代次相等。48kHz正常采样与事件服务率下，两次采样之间不能累积65536次重触发；停止音频请求不属于正常运行条件。

八度及延音接口与50MHz同域；按下锁音高，已有声音不随切档变高；延音关闭时只放开已松键声部，来源故障清理跳过延音。正式顶层暂无操作菜单，固定中档/延音关闭，触摸仍未实现。

## 固定钢琴预设及局限（当前音色）

`rtl/rom/piano_1024.mem`为1024点单周期，谐波系数255、95、48、26、15、9、5、3，其余为0；由`host/studio_model.py`按正弦叠加、峰值归一化、最近偶数舍入产生，范围±32767。没有预录整音PCM。

48kHz参数：Attack=96点、Decay=57600点、Sustain=0、Release=8640点。固定谐波/线性包络仍只是钢琴近似，没有琴弦共鸣、独立谐波衰减、踏板和混响；高音区需评估混叠，真实感尚未验收。

## 当前输入与显示隔离

2026-10-14正式入口 `piano_performance_top` 接入13个连续半音按钮，板载C4/E4是K00/K04的别名；接线见[接线说明](keyboard-wiring.md)。正式入口中PC与实体键共享16声部，按来源与音高匹配松键。独立测试入口 `instrument_uart_piano_top` 保持原两板键行为，原TB未修改。
主工程已适配C的队列、延音/八度内部接口和代次/清理规则；正式板级仍固定延音关闭、中音区，触摸未实现。实体来源0..12，预留16..127供其他输入，PC来源128..255；实体溢出只清0..15，PC失联只清最高位为1的来源。

显示只接状态/音频副本，不反压发声链路；详见[显示合同](display-rgb.md)。真实屏幕、像素PLL、外部时序和物理接线未确定，仿真隔离不等于显示已经上板。
