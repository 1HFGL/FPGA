# A双音色试听通路与接口合同

主板级入口 `music_uart_top`，公共系统 `music_performance_core`，发声核心 `voice_bank_music_pipe`。板键与电脑共享16声部，音色0为摇滚电吉他、1为钢琴，复位默认1。当前50MHz系统时钟、48kHz采样、16位补码输出；无CPU／PCM播放器参与发声。

## 数据流

```text
板键 → 同步／2ms消抖 → music_event_encoder ─┐
UART → 收字节／组行／music_uart_protocol ──┼→事件仲裁→voice_allocator
                                         └→16路音高／gate／重触发／预设
                                              ↓
                                   voice_bank_music_pipe
                                              ↓
                            synth_top → i2s_tx → PT8211-S／功放
                                              └→显示副本，无反压
```

复用master的同步消抖、分配器、串口字节层、音频时钟使能、帧缓存和串行发送；保留提前请求及按实际输出帧排空功放的修复。旧四声部顶层／合成及专用回归已退役；当前主线只保留一套16声部核心，功放排空测试已迁移到当前顶层。

## 样本有效时刻

- R0接受请求，锁存输入；每声部56拍，共享效果及总音量处理27拍。
- 16声部R923产生 `sample_valid`，下游R924接收缓存，计算至缓存18.48µs；4声部参数为R251/R252。
- 主工程 `REQUEST_LEAD_HALF_EDGES=60`，在下一真实音频帧前至少976个系统拍准备样本，严格大于924，至少52拍（1.04µs）余量。帧间距1041/1042拍；这不是把音频采样率提升为50MHz。
- `frame_start`是真正消费缓存的帧边界，不能用提前的 `sample_request`替代。边界同拍输入留给下一缓存；左右声道输出同一样本，启动首帧允许缺样本静音。
- `sounding`有效期间持续装入功放排空计数，结束后按3个实际输出帧排空。声音状态包括吉他箱体尾音，不能仅看按键或分配计数关闭功放。

以上是内部合同，不是物理按键到模拟输出的整机延迟。旧四声部R4及2.063030ms数字观测不适用于本版。

## 音色与定点

钢琴为48槽模态叠加：分量独立相位、幅度与衰减，采用C3/C4/C5/C6参考的频谱包络插值、轻微失谐和起音噪声；中低高音真实感仍需听音验收。吉他为31个分量加拨弦噪声和短暂起音滑落，经过4倍插值的失真与两级箱体低通。本轮经典摇滚候选只将失真表从round(12000*tanh(i*32/900))改为round(16100*tanh(i*32/1400))，减轻驱动并按C3/C4/C5/C6参考集匹配RMS；模态、箱体与包络不变。钢琴绕过吉他失真路径，换音色不会把正在响的旧音送入另一效果链。

相位32位、幅度Q16.8、衰减系数Q0.24、包络17位Q1.16。16路16位有符号数先扩位求和；钢琴总线右移3位，吉他保持总线右移2位，实际失真强度和补偿由新版传递表决定，效果输出后缩放。插值22位、最终显式25位相加并按已知范围取22位，再饱和到16位，避免隐式窄位回绕。重触发使用64采样点的连续性修正。

当前固定力度100。钢琴起音64点、松键释放4096点（约85.33ms）；吉他起音16点、释放2048点（约42.67ms），箱体有自身收尾。按住时分量自然衰减，没有固定1.2秒强制清零。已有全局实时弯音；尚无琴弦间能量耦合、延音踏板或混响。

`rtl/rom/piano_v3_modes.mem`存合成参数，`sine_1024.mem`存单周期正弦，`rock_v2_shaper.mem`存非线性传递曲线，均非录音PCM。生成见 `model/gen_piano_v3_rom.py`，吉他公式来自 `gen_rock_v2_rom.py`。参考参数与来源哈希见 `piano_reference_fit.json`／`piano_reference_sources.json`；原音频仅用于离线分析。独立NumPy检查同时对照ROM编码、4/16声部样本、每声部状态与尾音。

## 事件、音色选择与显示

UART的音符命令进入FIFO时锁存预设，实体键在按下边沿锁存预设；后续选择变化不能篡改队列里的音。正在响的声部保持原音色；同来源同音重触发采用新选择。来源区分板键与PC，同音不合并，旧松键不能结束被抢占后新归属的音；PANIC、HELLO重连和看门狗只清理PC来源，保持所选预设。复位恢复钢琴。

`music_display_top`把选中音色、实际混音和仍持有的已分配音符C4～C5的并集送显示；尾音不高亮，已被抢占的音符也不再高亮。音量／弯音显示已接已接受的目标值，复位为8／居中；中音区和延音关仍固定。参数显示不代表平滑已经结束，也不能当作两实体旋钮已接入。显示像素钟停止只丢副本，不能阻塞声音。

该接入层使用外部 `pixel_clk`和独立显示复位，尚无实际屏幕引脚、PLL或触摸控制器驱动。C独立工程保持原接口，正式13实体键／触摸、旋钮、八度、延音仍按PLAN推进。

## 全局音量／弯音及C接口

`music_controls` 与音频系统共用50MHz时钟。UART `CONTROL volume bend` 或C的同步端口提交完整参数对，音色预设与参数对独立。音量影响最终钢琴＋吉他混音，静音时相位、包络、尾音及声部归属继续运行；重新增大音量不会重新起音。每个音的起音力度仍固定100。

| 字段 | 单位、范围和复位 |
| --- | --- |
| `external_control_valid` | C送出的同步有效电平，上升沿与ready同时为1时接受完整参数对 |
| `external_control_ready` | 音频启动就绪且弯音码合法时为1；C应保持数据稳定直到接受 |
| `external_volume[6:0]` | 0..127；0静音，127为单位增益，其他码增益为码值/128；复位8 |
| `external_bend[10:0]` | 0..1024，对应−2..+2半音；512为原音高；半音数=(码−512)/256 |
| `monitor_volume` / `monitor_bend` | 已接受的目标值；弯音显示码=(码−512)×64，正端点夹到32767 |

UART与C同拍提交时，合法C参数对优先，UART返回 `ERROR 0 BUSY`，两者不会拼成半组参数，也不取消音符。非法C弯音码不接受；UART越界或语法错误整行拒绝。其他时刻采用最新接受的完整参数对。因此C应在初始化／旋钮变化时提交，不应一直拉高valid并反复发送未变化值，避免持续覆盖PC控制。C仍须保存另一旋钮的有效值，以完整对发送。

这些端口不是异步ADC引脚：C负责采集、断线策略、校准、中心死区、量程和必要的跨域握手。现有板级外壳把external_valid接0，只开UART控制；没有为未知模块分配新引脚。C独立ADS1115工程未修改，不能直接接其旧“亮度”值冒充弯音。

音量以无符号Q1.16增益存储，每个音频请求最多改变512（1/128）；弯音码每请求最多改变8（1/32半音），靠近目标时夹到目标，快速反向也不超调。全量程最长128个平滑步。请求沿同时锁存上一稳定增益／频率比，全帧16声部使用同一组控制；同步ROM在两请求之间完成查询。无新目标打断时，计入目标接受相位和流水线，至合成样本完全到达目标的保守内部上界为130个采样周期，约2.71ms。该数不包含ADC采集、UART／GUI等待、DAC串行化和模拟输出，不能用于宣称整机≤10ms。

弯音ROM文本每项5个十六进制字符，存储声明20位并显式读取低17位，高3位经模型检查为0，消除EX2526宽度提示。其有效数值为1025项无符号Q1.16：`round(65536 × 2^((码−512)/3072))`，由 `model/gen_pitch_bend_rom.py` 生成。1025码对应约0.390625音分步距；实测ROM频率比量化误差最大0.01456音分，仅为数值误差，不是声学测量。与吉他原有短暂起音弯曲合并后，再逐分量更新32位相位；保持相位连续，不重触发包络。混音以22×18有符号乘法得到40位结果，右移16位后显式饱和到16位。音量127且弯音512时，与加控制前的音频和状态逐位一致。

复位恢复8／512及增益Q16=4096，从首个音频请求即为低音量；HELLO重连、PANIC和PC看门狗只清理PC音符，保留音量／弯音及所选预设。`STATUS`报告的是目标接受情况。未来C更新可能覆盖较早的PC目标，PC不以旧确认自动重发。具体串口及上位机行为见 [协议](../host/STUDIO_PROTOCOL.md)。

经典摇滚失真表最大16100，仍为14有效位；箱体状态Q16.8的幅度上界16100×256，现有25位状态和宽乘加足够。未新增合成阶段，合同仍为R923有效／R924缓存。旧曲线仅在验证平台并行实例中使用，主板级工程只有一套共享核心。36组相干正弦诊断包含量化／插值／折回杂散，未证明全面降低；不能将本轮称作抗混叠完成。

## A阶段交接清单（本次精简）

当前交付为钢琴v3＋经典摇滚、16声部、音量／±2半音弯音平滑。用户对`music-classic16`反馈“应该是可以了”，仅记初步试听可用。

- 合成：`rtl/synth/voice_bank_music_pipe.v`；包络：同目录`instrument_env.v`。直接集成A核心需要这两个文件与下述前三份ROM。
- 参数与曲线：`rtl/rom/piano_v3_modes.mem`、`sine_1024.mem`、`rock_v2_shaper.mem`。全局控制另用`rtl/control/music_controls.v`与`rtl/rom/pitch_bend_1025.mem`。
- 重建依据：`model/gen_piano_v3_rom.py`调用`gen_rock_v2_rom.py`的吉他公式，并读取`piano_reference_fit.json`；另有`gen_pitch_bend_rom.py`和`gen_sine.ps1`。参考来源保存在`piano_reference_sources.json`，原录音不进入FPGA。
- 独立模型：`check_music_pipe.py`、`check_music_controls.py`、`check_music_range.py`；音色分析：`analyse_classic_rock.py`。参数重新提取才需要`fetch_piano_reference.py`／`analyse_piano_reference.py`，常规构建不联网。
- 测试：`verification/tb/music/`、`verification/fixtures/music_neutral_sha256.json`及`verification/scripts/run_music_tests.py`。测试中的4声部实例是同一核心的参数化检查，不是第二套旧合成源码；旧失真曲线仅由测试运行器解析生成，用于原黄金摘要回归，不进入综合。
- B集成：以主GPRJ列出的RTL为准，C提供逐声部gate／重触发／音高／预设，A输出有符号16位样本、valid和release_done。16声部R923有效、R924缓存；不套用旧R4接口。

不要将`upstream/fpga_interaction/rtl`整目录加入主GPRJ，它包含C独立工程同名模块。现有公共系统`music_performance_core`是已验证的接法；正式13键／触摸和旋钮事件需按上文合同接入。
