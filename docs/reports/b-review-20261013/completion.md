# B部分修复、延迟优化与目录迁移完成记录

日期：2026-10-13。对应批准的[实施计划](../../superpowers/plans/2026-10-13-b-latency-restructure-plan.md)。功能检查点为`abc41be`（尾音排空）、`4482f58`（提前采样请求）；本记录随目录迁移提交保存。最终推送目标按用户确认使用现有`master`，不创建`main`。

## 实际改了什么

- 修复功放在最后非零样本发送完之前关闭：用真实音频帧等待排空，复位仍立即关闭；短释放和原180ms释放都覆盖。
- 主钢琴将样本请求提前至下一帧前32/33个50MHz时钟，保留R0请求、R3有效、R4缓存和完整左右声道发送合同。通用模块默认仍兼容原模式，不修改音色或包络。
- 修复默认ModelSim入口的路径/依赖和失败判定；不再把退出码0或日志文件存在当作测试成功。合法参数与非法窗口、缺文件/缺工具、错误成功标记都有检查。
- 重整公共RTL、工程、验证、上位机和队友快照。活动GPRJ/Tcl/脚本/文档同步路径，process配置保留为受控输入；旧报告原文不批量改写。
- 四个旧演示顶层新增`.frame_start()`显式空接，解决新端口的EX3073警告，无逻辑行为变化。
- 双乐器网表审计不再依赖`error_acc_6_7`这类自动网名，改为从真实请求寄存器追踪连接；原ROM、MUX真值、引脚、约束及时序检查全部保留，另加6个误接负例。

未增加16声部、13键接入、旋钮弯音或显示物理连接；没有修改队友TB，没有烧录硬件。

## 延迟与资源结果

相同2ms消抖、原钢琴ADSR和50MHz/48kHz配置下，旧/新两模式各14个工况：

| 指标 | 修改前 | 提前请求后 |
| --- | --- | --- |
| 最大数字观测延迟 | 2.083210ms | 2.063030ms |
| 新空闲C4、固定力度、空事件队列的条件上界 | 2.187400ms | 2.167220ms |
| LUT＋ALU | 5903 | 5927 |
| 寄存器 | 2708 | 2710 |
| BSRAM / DSP | 4 / 8 | 4 / 8 |
| 现有约束最差setup / hold | +6.726 / +0.247ns | +5.891 / +0.127ns |

改善为20.180µs，不是数毫秒。测量起点是最后稳定的数字按键沿，终点是与新增事件相关、差分达到1LSB的完整左声道数字字；背景原有声音不能冒充新音响应。条件上界不包含任意事件积压、无限输入流或所有抢占状态，不能将它宣传为全工况整机上界。完整分析保留在[功能实施记录](implementation.md)。

主钢琴迁后先移走旧impl，再按受控process配置干净复建；结果与迁前候选一致。逻辑比同轮原基线增加24、寄存器增加2，无新增DSP/BSRAM/PLL，满足事先约定的增量与时序门槛。仍存在PR1014，完整相对BCK的DAC外部建立/保持预算尚未闭合；现有6条约束激活不等于板级全部时序已签核。

## 下一步边界

本轮代码/数字仿真/Gowin实现已验证，**没有实物验证结论**。下一步先按新的钢琴工程低音量上板验证尾音和串口，再完成外部DAC时序与物理接点→模拟输出的延迟测量；显示应按真实型号补齐供电、电平、PLL、CST/SDC后再接入。16复音、真实感音色和13键/旋钮属于后续实施，不能将本轮20µs优化或现有空闲资源当作这些目标已经完成。
