# 板载双乐器试听验证：2026-10-09

用户确认使用 Tang Mega 60K + NEO Dock31004 和板载耳机口，选择 KEY1 弹奏、KEY2 选色。新工程为 `fpga_project/instruments_board`，顶层 `instrument_presets_top`，KEY0复位。第0声部固定C4/力度100，其余三声部关闭；本轮没有新增外部接线、没有合并团队分支、没有由助手烧录硬件。

## 功能测试

ModelSim SE-64 10.6e 初轮 `All` 26项通过，之后只扩展板级测试的采样边界按键扫测，再单独运行最终 `PresetsBoard` 正负测试。最终数字为 **1534个串行字、768个R4输出与R5捕获、正270/负282个样本**，全部匹配，0编译/仿真警告。其他原25项源文件保持初轮哈希，不重复跑相同的旧用例。

板级测试缩短消抖及包络，保留真实50MHz/48kHz：覆盖按键抖动、保持只切一次、同时按双键、预设快照、保持/尾音不换色、采样间快速重按、9个消抖结束相位、复位及保持按键恢复、帧间隔1041/1042clk、BCK半周期16/17clk、LSBJ逐字解码、唯一启动欠载和功放不提前截断尾音。该测试核对数字传输，合成数学与默认包络仍由昨日独立核心用例覆盖。

负控 `PRESETS_BOARD_NEGATIVE_CONTROL` 故意翻转串行观察的首位，得到 `expected=0000 actual=8000`；ModelSim运行器明确拒绝，没有把错误改进下载RTL。

证据：`presets_all.log`、`all_first_manifest.txt` 是初轮完整回归；`presets_board_final.log`、`tb_instrument_presets.log` 和 `PresetsBoard_sha256.txt` 是最终扩展用例；对应negative文件为故意失败证据。原初轮板级用例日志保存在 `board_first_test.log`，不能与最终1534字统计混用。

## 高云实现

Gowin V1.9.12.03，GW5AT-LV60PG484AC1/I0，B版本，主时钟20ns。

| 项目 | 结果 |
|---|---:|
| 最差Setup（含输出预算） | +5.885ns |
| 寄存器间Setup | +9.201ns |
| Hold | +0.216ns |
| Recovery / Removal | +17.330 / +0.858ns |
| 最小脉宽裕量 | +6.809ns |
| Setup/Hold违例 | 0/0 |
| LUT / ALU / 寄存器 | 1219 / 535 / 774 |
| 锁存器 / BSRAM / DSP | 0 / 9 / 14 |

8个引脚全部 `Constraint=Y`，管脚/IO标准/上下拉与既有31004工程一致。5条SDC全部有效：主20ns时钟、仅异步按键和外部复位例外、四音频输出本地20/0ns预算，没有放宽内部时序。该输出预算不是PT8211-S完整外部建立/保持验收。

综合网表核对9块ROM共9216字、有效声部的KEY2至乐器锁存/波表/亮度/幅度连接，以及两级选择各128个真值组合。有效声部保留半幅正弦、拨弦、弦乐三表，其余三个无声声部各有两表及部分逻辑保留；资源数量不能当作本按键版能演奏四声部的证明。

综合14条NL0002为固定音符、静音声部及波表包装层级优化；已核对有效声部的弦乐数据仍在。P&R仍保留 **PR1014**：V22不是专用时钟输入，使用普通路由接全局时钟；本轮时序通过，但不能宣称无警告或擅改板上时钟管脚。

`timing_stage/`保留首次临时工程原始报告。正式仓库路径复跑后的报告、引脚表、位流SHA256及来源清单位于`timing_repository/`和`source_manifest.json`，以其对应的 `impl/pnr/instruments_board.fs` 下载。每次修改必须重新构建，不能只运行checker沿用旧结果。

## 用户操作

按[板载烧录说明](../../instruments-board.md)打开新 `.gprj` 或在 Programmer 直接选择新 `.fs`，使用 **SRAM Program**。下载成功后KEY0复位，KEY1试听拨弦；松手、KEY2切换、再按KEY1试听弦乐。下载、上板发声、模拟瞬态噪声、主观音色与外部时序仍等待本次实际操作确认；本报告不冒充实物验收。
