# 最新钢琴／摇滚16复音：烧录与试听验收

适用：`music_uart_top`、固件标识 `music-classic16`，钢琴v3／摇滚、16复音、总音量及±2半音弯音。下面是本项目建议的阶段验收标准，不是赛事官方评分表。2026-10-14用户对前一music-live16版反馈“应该是都通过了”。用户随后对经典摇滚版反馈“应该是可以了”，记录为本版初步试听可用；完整验收仍需下表逐项填写。


## 本轮先这样比较经典摇滚

1. 按本文SRAM Program下载新位流，重启上位机，确认握手`FW=music-classic16`。在“演奏”页选摇滚、音量8、弯音居中。
2. C4先短按再按住，听拨弦是否仍清楚；点“五度和弦”（C4/G4/C5），保持约2秒后“全部松键”；再点普通四音和弦，比较层次与粗糙感。
3. 运行低中高音、37音扫描和16音测试。16音比旧版可能略响，先小音量；它是压力输入，不用它评价悦耳程度。
4. 若要新旧板上对照，旧位流仍在`build/audition/music_live16_20261014_113257/music_live16.fs`；两次均选摇滚，使用同一输出设备、音量和弯音。单音已做RMS匹配，和弦约有0.5dB差异，听感比较时可小幅调外部音量匹配。
5. 本轮目标是适度失真、拨弦清楚、五度与普通和弦更易分辨，同时保留摇滚辨识度。若变得太干、太薄、太像干净电吉他，或和弦更糊／高音更刺耳，记为候选待调，不因软件测试通过就接受音色。

发布包里的`legacy_reference.wav`与`classic_reference.wav`为离线参考模型预览，依次为C3/C4/C5/C6/五度和弦/普通四音和弦，每段0.5秒；两文件均额外放大8倍便于电脑听音，该增益不在固件内，也不代表板上音量。它们不是板卡录音，更不会装入FPGA作为PCM播放。

这版先只改失真与响度补偿，箱体／拨弦参数不变。高频诊断未证明杂散全面改善，仍需要实际高音／弯音试听，不能宣称抗混叠已完成。之后仍按F1～F12检查完整功能。

## 2. 先确认连接和低音量

1. 先把有源音箱自身音量调低。若用耳机，先不佩戴，设置数字音量后再听；本版复位会回到数字音量8，仍应按实际输出设备调整。
2. 双击 `host/run_tone_studio.bat`。选择实际串口，115200、8N1；不要选“模拟设备”，同一COM不要同时开GUI和串口终端。
3. 连接后进入“演奏台”。应出现钢琴／摇滚选择、总音量、弯音和归中控制。确认总音量为8，弯音归中，等状态显示设备已经确认；这只是起始值，按输出设备调到舒适、可辨别的响度。
4. 通信日志应显示如下握手，随后STATUS应有PRESET、VOLUME、BEND。没有CONTROL能力或滑条始终禁用时，先排查固件／COM，不把无声当作音色问题。

```text
SYNTH/1 CAPS=NOTES,STATUS,PRESET,CONTROL MAX_VOICES=16 SAMPLE_RATE=48000 FW=music-classic16 TONE=PIANO_ROCK
```

原始串口替代操作（每行回车／LF；需先断开GUI）：

```text
HELLO
CONTROL 8 512
PRESET 1
STATUS?
```

原始终端连续3秒没有合法命令，会释放PC音符。长按听衰减时，每秒发送一次 `STATUS?`；GUI已自动查询。GUI“全部松键”只释放电脑音符，板键仍按着就会继续响，这是正常行为。

## 3. 功能验收：以下项目全部通过

每项填“通过／失败／未测”。测试音量须保持适中；不要以满音量轰鸣掩盖问题。前四项适合先做快速检查，其余用于本轮完整试听。音量／弯音尽量在刚起音后的1～2秒内操作，需要时重新触发和弦；已经自然衰减至听不见的旧音，不适合用来判断“恢复音量是否成功”。

| 编号 | 实际操作 | 合格表现 |
| --- | --- | --- |
| F1 启动与静音 | 不按键静听5秒；低外部音量下按KEY0复位3次，每次确认数字音量回到8 | 无持续自鸣、强烈嗡声或反复爆裂；无声部无故出现。启动瞬间若有明显爆音，记录为待修，不直接略过 |
| F2 板键及释放 | KEY1、KEY2分别按10次，约按200ms／松200ms；再同时按下，分别松开 | 每次一一对应、两音可同响、松开一个不误关另一个；全部松开1秒后无持续乐音，不挂音 |
| F3 钢琴单音与重按 | 钢琴下C4、E4、G4、C5各短按／长按；同一音连续重按10次 | 音高稳定，起音清楚，有自然衰减；没有随机漏音、双触发、突兀爆点或同一固定时刻硬切 |
| F4 四音和弦 | 点击“触发四音和弦”，听C4/E4/G4/C5，再“全部松键”；重复10次 | 同时听到和弦，非轮流只响最后一个音；无新增断续／爆裂，释放后恢复静音，PC独占时VOICE_COUNT最终回0 |
| F5 音域 | 弯音归中，点击“低中高音试听”和“C3–C6 音阶扫描”，至少细听C3/C4/C5/C6 | 无某个音无声、错八度、明显反向跳音或突变噪声；不同音区允许音量／衰减自然不同 |
| F6 音量 | 让四音和弦保持，依次调8→16→8→0，等0.1秒，再恢复8；整体保持在舒适响度 | 响度跟随，零音量时无乐音，恢复时接着原来的衰减，不重新敲击；不出现明显点击、断裂；静音时VOICE_COUNT可仍非0 |
| F7 弯音 | 总音量固定，保持C4或和弦；缓慢从中心到两端再归中，随后快速往返3次；尾音期间也调节 | 所有音一起连续升降，中心回到原调，不跳八度、重起音或留下错调；端点为±2半音，见下文音高对照 |
| F8 音色与旧音 | 钢琴和弦保持时改选摇滚，听旧音；再松开并重弹；反向再做一次 | 旧声部保持原音色，新触发采用新预设；同音重按采用新预设；两种预设明确可辨 |
| F9 摇滚声音 | 摇滚下弹单音、四音和弦，并做F6/F7 | 有拨弦起音和失真延续，音高仍可辨；允许预设失真粗糙，但不应随机炸裂、停顿、失声或噪声压过所有音符 |
| F10 16复音压力 | 点击“16音测试”，钢琴／摇滚各做一次，开始前松开板键 | 保持阶段STATUS报告VOICE_COUNT=16，输出不中断；松开后1秒内无持续乐音。密集音程不悦耳不等于故障；状态16本身不证明每声部声学独立 |
| F11 异常恢复 | PC持音时GUI断开并重连；再用原始终端发音后停止发送命令超过4秒；最后按KEY0并重连 | 正常断开能释放；停止通信后PC音自动释放，板键不被误关。重连可继续弹，复位恢复钢琴／8／中心，外部音量提前调低 |
| F12 连续演奏 | 两种音色各至少5分钟，交替单音、和弦、快速重按、音量和弯音 | 无随机卡死、长期挂音、持续底噪突然升高、掉声或重连后不能演奏。记录实际时长，不以短听代替 |

16声部包括释放尾音。第17个新音在全满时替换旧声部是预期抢占，不属于漏音；但不得因此卡死或留下永远关不掉的音。固定力度100是当前设计，改变NOTE_ON力度参数不会实现轻重触键。

## 4. 补测低／高音和16复音

GUI手动琴键显示C4～C5；新增“低中高音试听”覆盖C3/C4/C5/C6，“C3–C6 音阶扫描”覆盖全部37音，“16音测试”自动发16音、保持2秒并松开。请重启GUI取得新增按钮，保持演奏窗口前台；切换页面／窗口、手动弹键或改选预设会取消序列。

也可用原始串口终端（断开GUI，先完成HELLO和低音量设置）：

```text
NOTE_ON 48 100 0
STATUS?
NOTE_OFF 48 0
```

48=C3，60=C4，72=C5，84=C6。先测试这四个锚点，每音保持约2秒后松开；再将音符号从48递增到84，逐半音检查有无缺音。长听时每秒STATUS保活，测试完发PANIC。需要测尾音弯音时，紧接NOTE_OFF发送CONTROL，钢琴释放约85ms、吉他约43ms，手工慢操作可能已听不到尾音变化，可用串口终端连续发送两行。

保持C4并发送以下控制，可核对中心和端点。音量8仅为示例，单位是0..127原始码，不是百分比：

```text
CONTROL 8 512
CONTROL 8 1024
CONTROL 8 0
CONTROL 8 512
```

对应C4→D4→B♭3→C4。可分别与居中时NOTE_ON 62、58、60的声音比较，逐条执行、间隔约0.5秒。若测基频，以A4=440Hz的十二平均律为参考；本轮建议中心及端点稳定段误差不超过±5音分，需可靠的基频测量并记录方法，不能只凭失真音的最高频谱峰判音。仅靠耳朵的通过只能记“听感调音通过”，不能填写测量精度。

16复音优先用GUI新增按钮。若用已有命令行脚本，先在GUI设音量8／弯音居中，再断开GUI，两个值会保留。于仓库根运行，COM5必须换成你实际连接的COM号：

```powershell
& '.venv-studio/Scripts/python.exe' host/play_uart_chord.py --port COM5 --voices 16 --preset piano --seconds 3
& '.venv-studio/Scripts/python.exe' host/play_uart_chord.py --port COM5 --voices 16 --preset rock --seconds 3
```

脚本只向FPGA发送命令，声音仍由FPGA生成。它的16音是48～78、间隔2半音的压力输入，不是优美和弦；不要用这段的和声悦耳程度评分钢琴真实感。脚本结束会PANIC。听音和状态结果需要人工记录，脚本完成不等于听感通过。

## 5. 音色验收：不能仅凭“像琴”就通过

统一条件：不加混响、弯音居中、同一输出设备、舒适且接近的响度。参考采用PLAN已有的爱荷华大学Steinway Model B中等力度mf C3/C4/C5/C6单音；来源在 `model/piano_reference_sources.json`，参考有录音环境响应，不能把其房间尾响要求成本工程混响。没有参考可听时，先做功能与主观初评，比较验收记“未测”。

先听C3/C4/C5/C6，再听普通四音和弦。每个音关注：

| 项目 | 钢琴合格方向 | 需要继续修改的表现 |
| --- | --- | --- |
| 起音 | 有明确击弦感，初始较亮，随后自然柔和 | 持续像风笛／管风琴、尖锐金属敲击或明显“啪／啵”声掩盖琴音 |
| 持音 | 泛音和响度逐渐衰减，变化连贯 | 长时间一成不变的蜂鸣、周期性抖动、无故重起音或突然断掉 |
| 松键 | 较快但连贯地收尾，无多余点击 | 硬切爆点、莫名拖住不放或噪声尾巴；本版短释放本身不等于错误 |
| 低中高音一致性 | 各音区都能辨认为钢琴，同音区过渡连贯 | 只有C4像琴，其余像铃铛／口哨，某段特别刺耳或音量突然跳变 |
| 和弦清晰度 | 普通三／四音和弦层次可辨，强弱自然衔接 | 单音正常、叠加就严重糊成噪声、断裂、喘动或产生额外爆音 |

建议项目内采用5级主观评分：1=明显异常，2=电子蜂鸣感为主，3=能认出钢琴但合成感明显，4=已明显接近钢琴且无突出的刺耳／突变缺点，5=与参考很接近。**本阶段“钢琴音色通过”：四个锚点和普通和弦均达到4分以上，且上述项目没有明显缺陷。** 这是团队目标，不是客观复刻误差；记录试听者及条件。有两名成员时各自先评分再交流，意见不一致先记待优化。

摇滚通过条件：与钢琴盲听可区分，有可辨的拨弦起音、失真质感和稳定音高，普通旋律／和弦可听清，无随机爆裂、断续或持续刺耳噪声。全局音量在失真之后，因此降低音量不会消除预设自带的失真。当前未建立指定真吉他的匹配基准，不宣称“真实电吉他还原通过”。

## 6. 最终怎么判

- **功能试听通过**：F1～F12全部通过。任一项失败则功能未通过；未做的记未测，不补勾。
- **本轮音色通过**：功能通过，同时钢琴达到上述4分目标、摇滚达到可辨且稳定的条件。功能过但钢琴只有2～3分，应记“功能通过，钢琴音色待优化”。
- **整机／比赛验收**：本次试听不能证明≤10ms、≤5ms、完整DAC外部时序、正式13键／触摸／实体旋钮或整个赛题已完成。手感“不明显迟滞”只是观察，延迟数字要另用仪器测量。

建议记录如下，遇到异常写出可复现步骤：

```text

```

如需反馈声音，录一段15～30秒：C4短按、长按后松开、四音和弦、切换摇滚；注明设备和参数。音质问题尽量在同音高、接近响度下比较，不因更响就判为更好。

本次数字验证：101文件严格编译、7组RTL回归、60项PC测试、11,400点基线与7,500点调参独立对照通过；64轮反复演奏／恢复仿真不等于F12的实物连续5分钟。
