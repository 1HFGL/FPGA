# B部分：800×480中文RGB显示核心

2026-10-13用户确认：先写800×480并行RGB通用版，界面用中文，第二音色选吉他。本次实现显示及独立验证；显示钢琴/吉他状态，没有改变合成算法或接通音色切换命令。

## 1. 功能与文件

输入是已整理好的13键状态、音量、弯音、音区、延音、音色状态，以及最终混音样本的副本。输出是RGB888像素、DE数据有效、HSYNC行同步、VSYNC场同步。

已有：中文标题、音量条、带中心线的弯音条、低/中/高音区、延音开/关、13黑白键高亮、简谱数字、256点实时波形。最右“1”加高音点。高亮表示按键按下状态，不将松键后的尾音当成仍按住。

未包含：触摸、通用中文输入、背光电源控制、PLL、封装脚约束、屏幕初始化命令、正式音频顶层接入、布局布线和实物验证。这是直接并行RGB接口，不能直接用于SPI、HDMI、MIPI或LVDS屏。

| 文件 | 职责 |
|---|---|
| `rtl/display/instrument_display.v` | 总入口、各域复位、状态快照、波形缩放、流水线对齐 |
| `rtl/display/lcd_rgb_timing.v` | 像素计数、有效区、同步脉冲、帧边界 |
| `rtl/display/display_cdc_latest.v` | 稳定数据字＋请求/确认翻转的跨时钟信箱 |
| `rtl/display/display_wave_buffer.v` | 两页256×8位波形缓存，完整页在帧边界切换 |
| `rtl/display/piano_display_renderer.v` | 按坐标绘制、黑白键覆盖优先级及状态条 |
| `rtl/display/display_font24.v` | 中文/数字24×24点阵；来源和许可见 [字体说明](display-font/README.md) |

建议先读扫描计数，再读绘制器，最后看总入口和跨时钟传输。全部RTL及新增测试均为Verilog `.v`，中文注释说明接口、复位和有效时刻。

```text
系统时钟域                                像素时钟域
状态字段 ──完整数据字信箱────────────────→ 帧边界锁存 ─┐
音频副本 ──完整数据字信箱→显示增益/饱和→双页波形RAM ─┼→绘制→RGB/DE/同步
像素时钟 ───────────────────────────────→扫描计数 ───┘
```

没有显示ready回接音频发生器。像素时钟停止或显示跟不上时，只丢显示副本，音符事件仍走原来的实时通路。结构隔离不替代真实屏幕负载下的整机延迟实测。

## 2. 公共接口合同

| 端口 | 时钟域 | 定义 |
|---|---|---|
| `sys_clk` | 系统 | 项目预计50MHz；状态和音频输入在其上升沿有效 |
| `pixel_clk` | 像素 | 外部稳定时钟，最终由屏幕决定；不以普通逻辑随意分频生成 |
| `rst_n` | 异步 | 两显示域共同低有效复位，内部各自两拍同步释放；板级合并像素PLL失锁 |
| `key_down[12:0]` | 系统 | bit0..12为当前音区C、C#、D…B、上方C，可同时高亮多个键 |
| `volume[6:0]` | 系统 | 0..127，纯显示状态；条宽为输入×2像素 |
| `pitch_bend[15:0]` | 系统 | 有符号归一化显示码：-32768..32767对应约-2..+2半音，0为中心；集成层需按真实弯音格式换算 |
| `octave[1:0]` | 系统 | 0低、1中、2高，保留值3显示中音区 |
| `sustain` | 系统 | 1显示延音开，不实现尾音逻辑 |
| `instrument_guitar` | 系统 | 0钢琴、1吉他，接实际预设状态，不接切换脉冲 |
| `audio_valid`、`audio_sample[15:0]` | 系统 | valid为1的每个上升沿提供一个16位有符号混音样本；不等显示确认 |
| `display_sample_drop` | 系统 | valid时信箱忙则为1，仅诊断跨域副本丢弃；不统计波形页满后的主动丢弃 |
| `lcd_rgb[23:0]` | 像素 | `[23:16]`红、`[15:8]`绿、`[7:0]`蓝，DE为0时强制黑色 |
| `lcd_de`、`lcd_hsync`、`lcd_vsync` | 像素 | 与RGB同拍；DE高有效，HS/VS极性由参数指定 |
| `frame_start` | 像素 | 与输出左上角有效像素同拍的单周期标记 |

状态信箱不断取最新状态，不保存全部中间变化；成功传输的状态在帧边界统一显示，临近边界的变化可能再等一帧。极短键脉冲可能不显示，因此输入持续的按键电平，不输入press单拍脉冲。显示延迟与声音响应分开评估。

波形每页256个收到的样本，不抽取，48kHz时覆盖约5.33ms。没有零交越锁相，周期波形可能横向漂移；这是实时示意，不是测量示波器。两页共512字节，写满冻结，只在帧边界交换；等待期间允许丢显示样本。采样停止时保留最后一页，复位清除有效状态。

`WAVE_GAIN_SHIFT=3`默认把屏幕波形放大8倍：符号扩展、左移、饱和至16位、取高8位，合法范围0..8。它不改变耳机输出。预览测试使用0以展示满幅测试信号；预览锯齿由测试平台产生，不是乐器录音。

## 3. 时序、跨域与复位

默认只是仿真模板：水平有效800、前肩40、同步128、后肩88，总1056像素；垂直有效480、前肩13、同步2、后肩30，总525行；同步低有效。

刷新率=像素时钟÷1056÷525。例如33.264MHz对应60Hz，这是算术关系，不是屏幕时钟的选型结论。测试用33.333MHz，非最终PLL配置。

计数总长须在1..4096，ACTIVE/SYNC至少1，肩宽非负。顶层固定800×480布局，水平消隐总长至少2像素，以容纳换帧绘图流水线。改变分辨率需要调整布局，不能只改一个参数。

原始坐标被采样的时钟沿P0，RAM同步读、坐标/同步信号同时锁存；P1将对应颜色与DE/HS/VS一起寄存输出。原始帧最后一拍 `frame_commit` 在消隐区交换状态和波形页，保证整帧一致。

本核心没有 `lcd_pclk` 引脚。板级需按屏幕采样沿规定，从PLL及适当时钟输出资源送出像素时钟，并验证RGB/DE/HS/VS相对它的外部建立/保持时间。不能用综合报告自动默认时钟值代替屏幕工作频率。

两个信箱分别同步请求/确认。源数据从发请求起保持，直到确认返回；目的域看到同步请求后读取整个稳定字。音频与状态互不争用；波形RAM读写都在像素域，双页避免读写同页。

部署前须检查同步寄存器放置、控制路径和稳定数据总线的延迟预算，不能只给跨域路径加false-path。当前没有厂商CDC报告和板级布局布线，只能称协议仿真及综合通过。两信箱只支持共同复位，禁止只复位其中一端。

RAM不逐项清零以保留BSRAM推断；复位清除 `wave_ready/read_valid`，首个完整页发布前遮蔽未知内容。

## 5. 接入与学习下一步

先确定屏幕型号和原理图，核对RGB位数、排针、电压、背光、同步极性、像素时钟和上电流程，再创建显示板级外壳，保留原音频工程。

C提供13键电平及已应用的参数状态；A/B从最终混音处分出样本副本；B负责像素PLL、约束和顶层连接。现有钢琴顶层内部有 `sample_data/sample_valid`，需显式引出或在内部例化，不能用跨层引用代替公共接口。尚未实现的八度/延音/弯音也不能假装成已应用状态。

小实验：运行显示测试并看预览，改测试中的一位 `keys`，确认对应黑键/白键高亮；再移动帧中参数变化的时刻，确认下一帧才整组改变。无需连接屏幕。实物阶段另测正常刷屏下音频截止时间、欠载和整机最坏延迟。
