## 2. 布局与音符编号

前排8个白键音，后排5个黑键音。黑键分成2个和3个，分别放在C/D、D/E以及F/G、G/A、A/B之间；E/F、B/C之间没有黑键。

```text
后排：   C#4   D#4         F#4   G#4   A#4
前排：C4    D4    E4    F4    G4    A4    B4    C5
```

先画纸板排布，白键按钮中心距可从25～30mm试排；这只是建议，不是模块实测尺寸。实际PCB、排针和线缆必须放得下，同时试四指按键，确认不挤手。排布通过前不确定最终底板尺寸或钻孔位置。

线束编号按半音顺序，不按前后排顺序；本项目采用C4=MIDI 60的音名约定。下表是中档C4～C5的接线/映射参考，低档整体降一个八度、高档整体升一个八度；K00等为标签，不是当前顶层已经存在的端口名。

## 3. 底板、面板与固定

采用两层结构：绝缘底板承担按压力并固定各模块；上面板遮住PCB，只露出按钮与标签。板卡、配线板放键区后部，两个旋钮模块放键区上方，避免手指弹奏时碰到线和旋钮。

先测量一个模块并记录：PCB长宽、安装孔位置／直径、PCB厚度、按钮顶部高度、排针位置及插线后占用空间。照片带尺子可以用于讨论，正式打孔前仍要实测。

- 有安装孔：用尼龙螺丝和隔柱固定，PCB下面留出焊点空间。
- 无安装孔：用非导电支架或边缘夹持固定，避开元件、焊点和走线；按压时PCB不能弯曲或晃动。
- 面板开口：以实际按钮高度和行程为准。按钮伸不出面板时，采用露出开关的窗口或凹槽，不用厚面板硬压开关。
- 外观：白键音区域用白底标签，黑键音区域用黑底标签，音名放在手指不遮挡的位置；编号留在模块背面或线端。
- 接口：保留USB下载、供电、耳机插拔及散热空间；底部可加防滑脚。

双面胶只作样件临时定位，最终结构要能承受反复按压。不要直接把大琴键、杠杆或不匹配的机械键盘键帽粘到小开关上；需要更大触面时先核对兼容性、受力和回弹。此结构仍是短行程按钮，不能宣称已具备钢琴长行程手感。

结构材料优先用已有的绝缘底板、尼龙固定件、标签、线夹／扎带和防滑脚；缺什么补什么，不因外观整理新增处理器、按键扩展芯片或音频模块。需要工具加工时由具备条件的成员操作。

## 4. 配线与接入边界

线从键区向后集中，贴K00～K12标签，用线夹固定，在插头附近留适量余量，避免按键和旋钮操作拉扯杜邦接头。电源和地可用现有配线板分配，先核对面包板电源轨是否分段。

新增按键采用逐键独立读取，不默认改成矩阵扫描。每个模块的电源、地和信号脚按实物资料核对，不能只凭颜色或网上另一款模块的照片判断。

B先核对板卡与模块供电、电平和引脚，再完成实际接线表；FPGA输入侧不得接入5V高电平。两旋钮经ADS1115采集时，整板3.3V供电及I2C上拉条件也须核实。PMOD与复用排针不能重复计数为独立资源。

当前demo没有13键端口及新增外设CST约束。机械样件先不连接FPGA供电；电气接入应先验证一个外接键的读入，再逐步扩展到13键，不能仅因模块已固定就直接插满全部线。

## 5. 一次一个小实验

第一次安排约30～90分钟做机械样件，时间仅作学习建议，不是工期承诺。

1. 测量一个模块，在纸板上试排8＋5键布局，确认PCB和线缆不冲突。
2. 只固定一个按键，做对应面板开口，暂不接电；反复按压约50次，观察模块移动、PCB弯曲、按钮摩擦／卡滞和接头松动。
3. 单键可靠后做C4、C#4、D4三键小组，确认前后排手指能顺畅到达、按下后正常回弹。
4. 复制可靠固定方式到13键，加入标签和线束；试四指同时按下，再最终固定。
5. 接线表、输入代码和约束验证后，先接单键、再逐键测试13键；最后做四键和弦、第五键抢占、松键／尾音、重触发与复位测试。

单键移动就改固定方式；开关摩擦或不回弹就改开口／高度；插头受拉就改走线和拉力保护。一次只改一个主要因素，可靠样件保留作对照。

预期机械现象：模块不随按压晃动、按钮不卡住、线缆不挡手、下载／供电／耳机接口可用。预期13键声音现象仅在代码与约束接入后测试，当前两键位流不会自动识别这些新模块。
