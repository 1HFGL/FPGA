# 实体键与桌面装配

当前实物为NEO Dock31005＋60K核心板、八键按钮模块、两个Gravity模拟旋钮、ADS1115和7寸HDMI屏。八键模块全部承担白键C4 D4 E4 F4 G4 A4 B4 C5，另外五键承担C#4 D#4 F#4 G#4 A#4；按钮塑料颜色不决定音符。

唯一电气接线和模块K编号见[接线表](keyboard-wiring.md)，这里仅维护装配建议。板载KEY2切钢琴/经典摇滚吉他，13外接键不兼作功能键；两种音色和电脑共享16声部。

## 摆放与固定

将八键模块放前排、五键模块放后排，两旋钮放右上或键区后方，屏幕立在后侧。理想黑键位置为C/D、D/E之间两键，F/G、G/A、A/B之间三键；若成品五键模块间距不允许，先用清楚的音名标签对应，不切割共用PCB或强行拆焊。

底板用绝缘材料，模块用现有安装孔和隔柱固定；没有孔时夹持PCB边缘，避开元件/焊点。按下不能使PCB弯曲，排针和插头应留空间。白键音用浅色标签，黑键音用深色标签，音名置于手指不挡的位置。模块K编号贴在线端，与FPGA半音bit号分开。

纸板先试排并四指试按，再确定板材尺寸和孔位。尺寸、按钮高度、行程和安装孔以实际测量为准；短行程按钮不具备钢琴长行程手感。无需为本轮增加压力传感器、电子鼓、按键扩展芯片或处理器。

板卡周围留USB下载、供电、音频、HDMI插拔和散热空间，避免面板盖住散热片。线束集中向后，插头附近留弯曲余量并固定，按键/旋钮操作不能拉扯杜邦接头。屏幕单独5V供电，板卡电源保持已确认接法。

## 一次一个小实验

1. 断电固定一个模块，反复按压约50次，观察晃动、摩擦、回弹、PCB弯曲和接头拉力。
2. 确认1脚方向与3.3V/GND，再按最新位流接一个C4；检查声音和屏幕高亮。
3. 按八键K1～K8逐一检查白键音，再接五黑键；记录K6故障是否随按钮/线移动。
4. 做和弦、快速重按、松键尾音和KEY2模式切换，再用电脑补足16声部和第17音抢占。
5. 最后整理线束、固定屏幕与旋钮，记录新位流SHA256、实际接线和实物照片。

这些是实物待执行项目。当前仿真/构建证据见[验证说明](verification.md)，不能由数字测试替代逐键接线、模拟延迟或装配稳定性。

A参加音色试听与声部问题定位，C参加逐键/旋钮及事件检查，B组织显示、输出、接线与顶层验证；三人共同参与下载和上板，不把全部硬件调试集中给一人。
