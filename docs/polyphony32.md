### 实现与音色一致性

- `modal_voice_group16`各维护16个独立音高、相位、幅度、包络和触发状态，两组同帧启动；第二组保留原32声部的噪声种子16～31。
- `modal_coeff_rom_dual`由45个真正的GW5A双端口DPB组成；两组各用一个读端口。母表的31位频率增量、13位幅度、16位衰减无损装为60位，音高无关的初相和噪声标志单独还原。全部12288个系数逐字恢复，不减采样精度、谐波或可选音高。
- 两组的钢琴／吉他总线先以22位分别相加，再通过唯一的吉他非线性和箱体、总增益。不能把两份已限幅的16声部PCM直接相加，那样会改变吉他的失真和总音量。
- R0采纳输入快照，R1推进包络／噪声／微弯音并清零本帧累加器，R2开始读表；这切断了采样计数器到包络、噪声状态和混音累加器的长组合路径。
- 按键事件选择改为两个固定索引优先选择器，保持原轮转顺序、背压和溢出行为。

## 32 声部如何实现

两个正式入口 `piano_hdmi_top`、`piano_performance_top` 默认 VOICES=32；13 个实体琴键、UART 音符与未结束的释放尾音共用一个 32 声部池。第 33 个音按原分配策略抢占，容量不回绕。声部有独立音高、相位、包络、力度、预设和触发代次；效果器的回声不额外算声部。

不是直接把原串行循环加倍。`voice_bank_music_pipe` 在 VOICES>16 时每拍并行计算相邻两个模态分量，并将前一声部的包络／混音处理与下一声部的读表重叠。每声部仍计算原来 48 个槽，保留原有实际有效分量，不把空槽计为可闻振荡器。最多 16 声部的兼容配置保留原串行调度。

两份紧凑参数银行 `modes_even.mem`、`modes_odd.mem` 是原参数表使用区域的精确重排，不重新拟合、不降低位宽、不改衰减或频率；只去掉每组没有被核心读取的 16 个槽。所有钢琴、摇滚、正弦和失真原表不改。共享吉他失真／箱体、混音增益、饱和规则及三效果算法保持原样。

| 时序合同（50 MHz） | 旧 16 声部 | 新 32 声部 |
| --- | ---: | ---: |
| 核心 sample_valid | R923 | R803 |
| 核心下一拍缓存 | R924 | R804 |
| 无屏含三效果缓存 | R950 | R830 |
| HDMI 含明亮度与三效果缓存 | R953 | R833 |
| 相对最短 976 拍准备窗的 HDMI 余量 | 23 拍 | 143 拍 |

采样率保持 48 kHz，输出保持 16 位单声道复制左右声道。R833=16.66 μs 是采样请求到内部结果缓存的时间，不是按键到音响的整机延迟。参数化核心延迟：串行 `56*VOICES+27`，并行 `24*VOICES+35`，缓存再加 1 拍。

1. 带 HDMI 的主工程选 `build/audition/poly32_j13_20261023/hdmi_poly32_j13.fs`；无屏选同目录 `piano_poly32_j13.fs`。只使用本包与 31005／J13 接线，不选旧目录里的同名历史文件。

3. 关闭旧上位机后重新打开 `host/run_tone_studio.bat`，连接实际 COM 口和 115200。日志应有 `MAX_VOICES=32`，容量显示 32；没有它就不要按新版本验收。
4. 不按实体键，在演奏页点“32音测试”。程序持续约 2 秒发送／保持 MIDI 48～79 的 32 个不同音，再全部松开。状态应达到 **32 / 32**、无新增抢占，结束并等待释放后回到 0。这是密集音簇压力测试，不是悦耳和弦演示；耳听不能单独证明 32 声部。
5. 上位机测试只用 NOTE_ON/NOTE_OFF/PANIC，不切音色或改音量；KEY2 切乐器，实体旋钮调音量。按“全部松键”、换页面或切换窗口会停止自动序列。
6. 合格标准：单音音高／音色与原固定三效果版一致，32 音时没有卡音、周期性断续或数字爆音，释放后自然回到静音；长时间轮流弹奏仍可正常松键。默认混音与饱和保护沿用旧版，满音量密集音簇不是推荐听感条件。

## 复现

在仓库根目录执行，按本机实际安装路径替换 Python、ModelSim 与 Gowin 路径：

```powershell
python model/pack_modal_rom.py --check
& verification/scripts/check_verilog.ps1 -ModelSimBin D:/modelsim1/win64
python verification/scripts/run_final_tests.py tb_poly32_core tb_poly32_hdmi tb_poly32_uart --bin D:/modelsim1/win64 --gowin-simlib C:/Gowin/Gowin_V1.9.12.03_x64/IDE/simlib/gw5a/prim_sim.v
& projects/hdmi/build.ps1 -Gowin C:/Gowin/Gowin_V1.9.12.03_x64/IDE/bin/gw_sh.exe -Python python
& projects/piano/build.ps1 -Gowin C:/Gowin/Gowin_V1.9.12.03_x64/IDE/bin/gw_sh.exe -Python python -EvidenceDirectory build/piano32
```

集成测试自动创建 `build/regression/poly32/`。原模态表若有意改动，先运行 `python model/pack_modal_rom.py` 更新两份银行，再重跑逐点参考测试；不能只更新一份参数表。参考测试需要仓库保留上述基线提交。
