# ADS1115 双旋钮前端（2026-10-12）

## 当前行为

`ads1115_if` 轮流采集 A0/A1，只有两通道的完整事务都成功才更新整组
`raw_flat` 并产生 `sample_valid`。所有发送字节都检查 ACK；NACK 会中止整组采集、
发 STOP、等待后从 A0 重试。故障只在下一组完整采集成功后清除，失败时保留旧数据。

`ads1115_knob_if` 处理有符号读数和两通道独立端点校准：负数归零，达到最大
校准码后饱和到 127。归一化采用常数倒数乘法和一级寄存器，避免大组合除法器。

`adc_knob_if` 从复位开始检测采样超时。收到 READY_SAMPLES 组有效样本时就绪；
超时撤销就绪并重置预热计数。封装在 I2C 故障时立即屏蔽 param_ready。
故障期间保持上一次有效旋钮参数，不再发送虚假有效脉冲。

## 默认参数

| 参数 | 默认 | 说明 |
|---|---|---|
| I2C_ADDR | 0x48 | ADDR 接 GND，核对模块拨码 |
| PGA / DR | 001 / 100 | +/-4.096V，125uV/码；128SPS |
| CH0_MUX / CH1_MUX | 4 / 5 | AIN0-GND / AIN1-GND |
| CONV_WAIT | 500000 | 50MHz 下每通道等待 10ms |
| RAW_MIN_0 / RAW_MIN_1 | 0 / 0 | 两路最小校准码 |
| RAW_MAX_0 / RAW_MAX_1 | 26400 / 26400 | 默认 0..3.3V 旋钮 |
| FILTER_SHIFT | 2 | IIR 每组向目标移动约 1/4，最终到达端点 |
| SLEW_STEP | 8 | 每组最多移动 8 个单位，差值不足时直接到目标 |
| READY_SAMPLES | 16 | 有效采样预热，不保证已经完成全幅稳定 |
| FAULT_TIMEOUT | 5000000 | 50MHz 下 100ms 无有效采样时报超时 |
| RETRY_WAIT | CLK_HZ/100 | NACK 后等待约10ms再重试 |

knob_value_flat[6:0] 是旋钮0，[13:7] 是旋钮1。
默认标定下 0V -> 0，1.65V -> 约64，3.3V -> 127。
改变 PGA/供电时必须同步调整校准码，实际最小/最大码应上板测量。
校准范围满足 0 <= RAW_MIN < RAW_MAX <= 32767。
外部在 knob_sample_valid 有效时读取参数；归一化寄存器增加一个时钟的流水延迟。

## 引脚状态：待实物确认

现有 CST 仍保存 sda=H19、scl=H20，用于验证现有工程的逻辑实现。
这不是已经确认的外接3.3V排针接线方案。
NEO Dock31004 Rev1.4 原理图中，这两路为 JOYA_FC_3V3 / JOYA_TXD_3V3，
经过 U50（TXS0108E）连接到 Joy-Con 的1.8V侧。芯片球位不能作为排针编号。
应优先选明确引出的、未被 A/B 占用的3.3V GPIO，再修改正式 CST。

旋钮 VCC/GND/SIG 三芯接 ADC 模拟输入侧，信号分别接 A0/A1，按模块标识核对针序。
ADS1115 再通过 SDA/SCL/VCC/GND 接 FPGA，需核对 I2C 上拉电压。

## 自检与边界

已有正常采集、地址匹配、各写字节NACK、开机无ADC、掉线、重连、有符号负数、
零点、中点、满量程、饱和、平滑不越界测试。完整 C 测试共12项。
脚本同时检查 PASS/FAIL 和进程退出码，不再仅依赖 $finish。

仍用固定转换等待，模型未完整模拟真实转换就绪时序；后续可查询 OS 位或 ALERT/RDY。
I2C 仍是单主机、SDA开漏、SCL推挽；未实现时钟拉伸、SDA卡低后的总线清理或仲裁。
旋钮尚未接入统一的13键和A/B板级顶层，未下载实物测量响应或声音。
本次新构建位于 verification/knob_20261012；根目录 impl 中的历史位流和报告
不能视作本次版本结果。构建通过也不证明 H19/H20 外部接线可用。
